版本更新

9.18 本次更新

2026.09.18

项目结构整理

进一步拆分和整理项目文件，将较大的功能文件拆分为多个独立模块，降低后续维护和修复时不同功能互相影响的情况。本次结构调整范围较大，如遇异常欢迎及时反馈。

新增 MCP 功能

新增 MCP 功能入口，支持添加和管理 MCP 连接、连接状态检测及相关工具调用，并优化 MCP 与聊天功能之间的配合。

数据与存储

修复存储相关问题，优化部分数据保存、读取及恢复逻辑。

音乐功能优化

修复音乐搜索相关问题，新增扫码登录，优化音乐服务连接及部分播放器逻辑，并修复部分音乐无法正常获取或播放的问题。

新增思维链功能

新增独立思维链设置，支持配置思考内容相关规则，优化思维链与正常回复之间的处理，并新增对应的设置与检查逻辑。

生图、时间与小剧场

优化两个生图功能及音乐功能，修复部分 API 参数、生成及调用异常；优化时间感知、小剧场功能及相关生成与显示逻辑。

字体与世界书

优化字体相关设置和部分页面的文字显示效果，优化世界书功能，修复部分世界书使用及显示问题。

新增双语功能

感谢 1900老师 授权。支持聊天双语输出，优化原文与翻译内容的处理，可以根据实际需要控制相关功能。

功能独立开关

新增心声、动态、微博、情侣空间等功能的独立开关，默认关闭。关闭后不会向模型注入对应功能的提示词，可减少无关提示词对当前聊天的影响。

API 与提示词管理

优化 API 属性及相关参数处理，提高不同 API 配置下的兼容性；新增自定义提示词与提示词分层管理，优化提示词管理入口及检查机制。

分层设计灵感来源于 1900老师，感谢分享与授权。

结构检查机制

对项目结构增加更多检查机制，用于检测拆分后的模块、思维链、音乐及相关功能是否正常加载。

本次更新涉及较多底层文件拆分。如发现以前正常的功能无法使用，请反馈具体功能及操作步骤。
